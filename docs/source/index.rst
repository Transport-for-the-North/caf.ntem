Welcome to CAF.ntem's documentation!
===========================================================

Common analytical framework (CAF) Python package for extracting and analysing NTEM data.

NTEM (National Trip End Model) is a UK Department for Transport (DfT) model that forecasts
trip end data up to 2051. More information and the data from this model can be found on 
[data.gov.uk](https://www.data.gov.uk/dataset/11bc7aaf-ddf6-4133-a91d-84e6f20a663e/national-trip-end-model-ntem).

CAF.ntem allows easy querying of this dataset through Python, allowing users to extract
planning, trip end and car ownership datasets. CAF.NTEM provides both a 
command-line interface (CLI) and Python API.



Common Analytical Framework
---------------------------

This package is sits within the `Common Analytical Framework (CAF) <https://transport-for-the-north.github.io/caf_homepage/intro.html>`_,
which is a collaboration between transport bodies in the UK to develop and maintain commonly use
transport analytics and appraisal tools.
